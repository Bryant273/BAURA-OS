# Registre des pilotes et codes tiers

Modèle à remplir. **Aucune entrée n'est inventée** : le registre est vide tant
qu'aucun code tiers n'est entré dans le dépôt. Une ligne par code externe, avant
sa fusion.

| Pilote BAURA | Source (URL + commit/version) | Licence (SPDX) | Nature : copie / adaptation / inspiration seule | Fichiers concernés | Revu par / date |
| --- | --- | --- | --- | --- | --- |
| _(vide)_ | | | | | |

Règles : une ligne « inspiration seule » signifie que la documentation a été lue
mais qu'aucun code n'a été copié ; une licence GPL sur une ligne « copie » ou
« adaptation » impose de traiter la décision n°1 de `08_DECISIONS_A_PRENDRE.md`
avant fusion.
