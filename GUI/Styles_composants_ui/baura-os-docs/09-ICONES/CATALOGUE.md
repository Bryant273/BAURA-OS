## Noms Lucide absents de cet ensemble (utiliser le remplacement)
Pendant la rédaction de `07`, ces noms demandés n'existent pas dans les 550 : `alert-circle`→`circle-alert`, `alert-triangle`→`triangle-alert`, `check-circle`→`circle-check`, `book-open`→`bookmark`, `ellipsis`→`menu`, `lock-keyhole`→`lock`, `mic-vocal`→`mic`, `notebook-pen`→`pen-line`, `plane`→`wifi-off`, `scan-search`→`scan`, `sun-moon`→`moon`, `swords`→`puzzle`.
Astuce : compiler avec `-DBAURA_ICON_DEBUG` affiche sur `stderr` tout nom introuvable.
